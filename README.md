# Logistics Delivery Performance Analytics



## Sobre o projeto



Este projeto tem como objetivo analisar o desempenho logístico de entregas no e-commerce brasileiro, utilizando SQL e Business Intelligence para identificar padrões, avaliar indicadores operacionais e gerar insights para a tomada de decisão.



O projeto faz parte do meu desenvolvimento profissional em Análise de Dados, aplicando conhecimentos de planejamento logístico a um cenário real de negócio.



##### Tecnologias previstas



* PostgreSQL: armazenamento e consultas SQL.
* DBeaver: gerenciamento e exploração do banco de dados.
* SQL: análise, transformação e validação dos dados.
* Power Query: tratamento e preparação dos dados.
* Power BI: modelagem, indicadores e visualização.
* DAX: criação de medidas analíticas.
* Git e GitHub: versionamento e documentação.



#### Fonte de dados



Brazilian E-Commerce Public Dataset by Olist, disponibilizado no Kaggle.



https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce



#### Indicadores planejados

#### 

* Volume de pedidos entregues.
* Percentual de entregas dentro do prazo.
* Lead time médio de entrega.
* Evolução dos atrasos.
* Análise regional das entregas.
* Análise dos valores de frete.
